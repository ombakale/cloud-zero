# cloud-zero

Multi-Cloud FinOps Intelligence & Live Cost Explorer for AWS and Microsoft Azure.

## Features
- **Vision UI Design System**: Space navy theme with glassmorphic cards, glowing metric badges, and Inter typography.
- **Dynamic Cloud Onboarding**: Direct connection workflow for AWS (Access Key & Secret Key) and Azure (Tenant ID, Client ID & Secret).
- **Live Cloud Telemetry**: Real-time integration with AWS Cost Explorer and Azure Cost Management APIs.
- **Provider Isolation**: Dedicated single-provider experience ensuring zero cross-cloud pollution.
- **Database**: Zero-dependency store with Neon Serverless PostgreSQL support.
